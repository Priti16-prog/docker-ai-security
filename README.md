# AI-Powered Docker Security Analyzer

A container security project that combines **Docker, Trivy, and AI-assisted vulnerability analysis** to identify security risks in containerized applications and provide actionable remediation recommendations.

## Overview

This project demonstrates a practical approach to securing containerized applications using vulnerability scanning and security analysis.

A Node.js application is containerized using Docker and scanned with **Trivy v0.52.2** to identify known vulnerabilities in the container image, operating-system packages, and application dependencies.

The generated Trivy vulnerability report is then analyzed using AI to understand the findings and provide security recommendations.

### Security Workflow

```text

        ▼

        ▼
```

## Docker

### Build the Docker Image

Build the application image using the Dockerfile:

```bash
docker build -t docker-ai-security:v1 .
```

### Verify the Image

```bash
docker images
```

### Run the Container

```bash
docker run -d \
  --name docker-ai-security \
  -p 3000:3000 \
  docker-ai-security:v1
```

### Verify the Running Container

```bash
docker ps
```

### Stop the Container

```bash
docker stop docker-ai-security
```

### Remove the Container

```bash
docker rm docker-ai-security
```

## Security Scanning with Trivy

The Docker image is scanned using **Trivy v0.52.2** to identify known vulnerabilities.

Run the following command:

```bash
trivy image docker-ai-security:v1
```

The scan evaluates the Docker image and reports information such as:

* Vulnerability ID
* Affected package
* Installed version
* Fixed version
* Severity
* Vulnerability status

The complete Trivy scan output is available in:

**[Trivy Vulnerability Report](reports/trivy-report.txt)**

## Security Practices

The project incorporates the following container security practices:

* Uses a lightweight Alpine Linux base image.
* Uses a non-root user for running the application.
* Uses `.dockerignore` to exclude unnecessary files from the Docker build context.
* Uses `npm ci` for reliable and reproducible dependency installation.
* Performs vulnerability scanning using Trivy.
* Maintains security reports for review.
* Recommends regular updates to dependencies and base images.
* Encourages vulnerability scanning before deployment.

---

## Security Findings

The security scan identified vulnerabilities in third-party packages and dependencies.

Some findings originated from the underlying Alpine Linux base image and application dependencies.

The security analysis recommends:

1. Regularly update the Docker base image.
2. Keep Node.js and npm dependencies up to date.
3. Rebuild Docker images after security updates.
4. Run vulnerability scans before deployment.
5. Prioritize remediation of critical and high-severity vulnerabilities.
6. Review vulnerable dependencies and apply available fixes.
7. Integrate automated security scanning into the CI/CD workflow.
